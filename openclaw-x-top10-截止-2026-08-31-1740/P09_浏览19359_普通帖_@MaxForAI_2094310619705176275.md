## 正文

WOW，OpenClaw 2.0发布了。

这是 @openclaw  至今最大的一次更新：933 名贡献者参与，其中 569 人是第一次贡献，一口气合并了超过 16000 个 PR，差不多占 OpenClaw 历史全部 PR 的一半。

这次几乎把整个项目都翻了一遍，包括安装、消息、Memory、Skills、模型、自动化、浏览器、原生 App、插件和安全。

最直接的变化是更好用了。

首次安装时，OpenClaw 会自动利用电脑里已经存在的 ChatGPT / Claude 订阅、API Key 和本地模型，砍掉大量前置配置。

浏览器端也被完整重做，现在可以直接聊天、继续任务，以及实时看 Agent 工作。

另外还加入了 Shared Cloud Sessions，可以把另一个人直接拉进当前 Agent Session，任务和上下文一起共享，OpenClaw 官方直接把它称为 multiplayer。

有意思的是，这个 2.0 原本根本没计划做这么大。

团队最开始只是想简化安装、重做浏览器，结果一路改下去，最后把整个 OpenClaw 都重构了一遍。

他们此前 230 天发了 106 个版本，这次却罕见停了接近 7 周。

然后憋出来了 2.0。

但真的还有多少人在用吗？
