## 正文

怎么用 Jev，以及 100x 实际从哪来。

安装大约 10 分钟：waitlist（当天过）→ npx skills add typesafe-ai/skills --skill typesafe-ai → 建 API key → prompt 里说 use the TypeSafe skill。

100x 不在模型本身，在你把它放哪。不要用 Jev 换掉 LLM，而是删掉那些从来就不该走语言模型的调用：下一步用哪个工具、是不是垃圾、这块是否相关、要不要人、这次 diff 是否危险。

升级顺序：
1. 每个判断改成类型化问题（Choice / Score / Noul）
2. 一次请求里并行问完，输出 token 免费
3. 阈值看置信度：<0.5 升级大模型或人，不可逆操作要 0.85+
4. 绝不让它发明选项，候选列表用代码从 DOM/检索/tool trace 建
5. 放进 loop：路由便宜模型、执行前 gate、执行后 judge
6. 今晚先做 compaction：给每次 tool call 打分，丢掉死的，留下的原文保留

诚实部分：目前只文本；宽泛基准打不过前沿模型。但有人 zero-shot 跑 18514 封邮件 98.33%，对比用 14800 条标注训练的 TF-IDF 98.39%，总成本 $1.12。
