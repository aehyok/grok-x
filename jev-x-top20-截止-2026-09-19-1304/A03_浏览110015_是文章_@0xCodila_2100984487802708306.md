## 正文

杰文斯悖论：资源使用效率提高，总消耗不降反升。这是 LLM 和 Agent 的全球问题。@typesafeai 的 Jev 被作者写成「能省 101% 钱和时间、提高用 AI 效率」的 2030 栈，现在就该装。

Browser Use 把 Jev 放进 agent，7 秒找到航班、$0.0039。有意思的是：Chief of Staff 一天都在选工人、检查结果、决定是否继续。每个分叉都可能在有用工作之前再调一次模型。Jev 给这些决策单独一个模型。

写作 agent 继续写，研究 agent 继续研究，它们之间的小判断变成可检查、可计价、可替换的组件。先做独立任务路由器：输入任务，让 Jev 选目的地，把交接存在本地。再跑 Browser Use 的完整浏览器 agent。

### 10 步

01 找出 agent 里 Jev 能接手的部分。Jev 不能写 briefing、不能写代码、不能用散文解释推理。适合：资料够不够、下一个 worker、草稿能不能审。抓源、写段落、存文件仍归工具和生成模型。精确规则（如 10 步就停）写在代码里。

02 Playground 里先做一个决策。Choice：「下一个 worker 该谁？」research / write / review。

03 接一次 API。Python 3.12+，隔离环境 + 官方 SDK。Key 不要进源码。也可用 `npx skills add typesafe-ai/skills`。

04 把请求变成保存的 handoff。`chief.py` 写出 JSON 到 `queue/research|write|review`。作者把 review 阈值先设 0.85。Confidence 不是准确率百分比。

05 问能落地的问题。Choice / Score / Noul。Jev 看不见 question ID；真正要求写在问题和选项描述里。给证据，不要只说「researcher 做完了」。

06 偷 Browser Use 最好的点子：每次重建菜单。页面动作每次点击后都变。选项要从「现在存在且可用的 worker」建。大候选先代码过滤，再 Score，再 Choice（最多 255）。

07 别让问题互相等待。同一 state 上的 worker、紧急度、审批可以一次并行问。问题之间读不到彼此答案。Browser Use 还把浏览器协议调用中位数从 1092 降到 101。

08 给隔夜工作一个停点。允许收集和起草，停在 review。发布要单独权限。还要动作上限、花费上限、保存进度。Browser Use 在 Jev 选 DONE 之后独立检查结果。

09 看清标价买到什么。Jev 1.13：$0.042 / 百万输入 token，输出免费。1000 billed input tokens/决策、1 万次决策约 $0.42。航班 demo 的 $0.0039 对应记录的 90558 Jev 输入 token + 文本助手费用。浏览器成本在外。Vercel fx 团队报安全分类比 GPT-5.6-luna 大约快 5–18 倍。按完成任务记账。

10 用例：控浏览器；给 1018 篇 AI 论文分类 $0.08、中位 256ms；收件箱分流；在模型之间路由任务。

### 转移

LLM 创造工作 → Jev 决定下一步。真正的 alpha 不是 7 秒航班，而是发现 agent 里多少昂贵 LLM 调用从来就不需要生成。
