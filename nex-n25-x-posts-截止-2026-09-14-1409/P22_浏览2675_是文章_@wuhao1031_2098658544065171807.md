## 正文

我不会编程，但我让 AI 把“锁鲜”变成了一次关于时间的互动实验。
我平时做品牌和包装设计。
前几年做过一款“锁鲜枸杞”，包装上的核心词就是两个字：锁鲜。
这次试 Nex-N2.5 Pro，我不太想拿它跑一道题，也不想再做一个普通的产品官网。
我只给了它原来的产品图和包装平面。

然后提了一个很简单的想法：
如果“锁鲜”，真的可以锁住时间？
最后我把页面压得很简单：
一罐产品，一句话，一个按钮。
正常状态下，枸杞、微尘和光线在产品周围缓慢流动；
点击 「锁住时间」，运动逐渐减速、静止，周围的光线慢慢向产品收束；
再点击 「释放时间」，枸杞和粒子重新散开，时间继续流动。
我不会前端，也不会为了这个效果专门去学一遍交互开发。
这次是在 Kilo Code 的 Agent 环境里，通过 OpenRouter 调用 Nex-N2.5 Pro。

从创建项目文件、写 HTML / CSS / JS，到实际运行页面和继续修改，它确实把一个原本只停留在脑子里的设计想法，变成了可以真正操作的东西。
当然，过程并不是“一句话就完美”。
第一版能运行，但视觉很像普通网页。有一次它甚至判断交互已经正常，我自己实际点过以后，才发现按钮仍然有问题。
后来我继续从设计角度给反馈：
减掉网页感、强化产品主体、重新处理“锁住”和“释放”的节奏，再把“时间”这个抽象概念变成光、轨迹和运动状态。

最后才到了现在这一版。
做下来最大的感受其实很简单：
它能把“不会编程”这道门槛跨过去，但它不天然等于“好设计”。
代码可以自己写，交互可以自己跑，最后那一下创意、构图、节奏和审美判断，还是得设计师自己来。
但反过来看，这件事也很有意思。
以前很多想法不是想不到，而是实现成本太高，所以最后就算了。
现在至少可以先让 Agent 把它跑起来。
AI 最有意思的地方，也许不是替你想，而是让以前做不出来的想法，第一次有机会真的动起来。

这次使用的是 Nex-N2.5 Pro，通过 OpenRouter 接入。
