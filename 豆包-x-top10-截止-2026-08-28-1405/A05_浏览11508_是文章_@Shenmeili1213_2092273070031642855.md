## 正文

今天，8月25日，字节的豆包工作正式上线。 官网下载、登录或升级，公开口径可领30天订阅权益。
易观《2026年Q2中国AI办公智能体市场报告》：今年6月，17款主流桌面端AI办公智能体合计月访问量破6000万；腾讯WorkBuddy以2097万排第一，超过第二、第三名之和。

大盘已经六千万次访问了。 新品又把「免费试用一个月」摆到桌面上。
可评论区还在吵谁第一。 真干活的人，少。
刷到这里，先别收藏评测。 问自己一句：
你装上了吗？装上以后，干过一件看得见的真事了吗？
很多人停在「打开看了看」。 界面很新，按钮很多，手又缩回去了。 等于白拿了那30天。
今晚路修短。 5步。装、登、授权、派活、验收。 跑完再睡觉。
不做搬家。 不做流水线。 不做三国杀。
只交一个看得见的活： 一个练习文件夹，按类型整理好，再给你一张清单。

0. 半分钟分清：会聊 ≠ 会交活
数字再大，也救不了「打开看了看」。
你用过豆包、用过 ChatGPT，多半是这种感觉——
你问，它答。 周报文字出来了，你还得自己复制进 Word。 表格思路有了，你还得自己新建 Excel。
会聊：给你字。 会交活：拆步骤、动文件、把结果放到你能打开的地方。
豆包工作卖的是后一种。 公开口径也围着「工作任务」转：你说目标，它拆计划、调工具，尽量把活干完。
今晚验收标准就一句：
我没有用手把文件一个个拖进子文件夹。
文件夹已经分类完，清单能给人看。
过了这关，你才算「用过办公 Agent」。 没过，只算「看过一个新 App」。

步骤1｜装（大约 3 分钟）
打开官网：https://www.doubao.com/work
下载电脑版（Windows / Mac 选你的）
装完，打开
公开信息里还提到：也可以在豆包电脑版里切到工作模式；飞书较新版本左侧也有入口。
第一夜建议：先走独立电脑客户端。 少一个「我到底进没进对地方」的变量。
打卡：
[ ] 能看到「新工作任务」一类主界面
[ ] 输入框能打字
卡住了？多半是下载包没装完，或打开了普通聊天版豆包。 退出重进，确认窗口标题/模式是「工作」相关，再往下。

步骤2｜登（大约 2 分钟）
按提示登录。常见是：
手机号
飞书账号
抖音 / 豆包扫码
公开宣传里写过：下载电脑版可领一段时间的订阅体验（常见说法是 30 天，以你弹窗为准）。
登录后如果跳出「立即体验 / 额度」——点开看一眼就行。 今晚别在套餐页纠结。先证明它能干活，再谈续不续。
打卡：
[ ] 登录成功
[ ] 能新建或进入一个工作任务

步骤3｜授权，只给一个「沙坑」（大约 5 分钟 · 最重要）
这一步，很多人要么不敢授权，要么一把把整个磁盘甩进去。
两个都容易出事。
今晚只建一个练习夹：

往里面扔 10～30 个杂文件就够：
几张截图
一两个 PDF
一两个表格 / Word
别塞身份证、合同原件、客户手机号
人话： 这是沙坑。 摔了不心疼。 练的是「它动手」的手感，不是整理你人生。
授权原则记一句：
只给必要的，不给多余的。
打卡：
[ ] 豆包练习-第一夜 已建好
[ ] 杂文件已放进去
[ ] 任务里能选到 / 指向这个文件夹

步骤4｜派活（大约 5 分钟）
新建工作任务。 把下面这段复制改路径后发出去（文件夹名以你实际为准）：
整理文件夹「豆包练习-第一夜」里的文件：
1）按类型分成子文件夹：Word / Excel / 图片 / PDF / 其他；
2）把文件移进对应子文件夹；
3）完成后给我一份清单，包含：文件名、分到哪一类；
4）先列出你要做的步骤，我确认后再执行；
5）不要删除任何文件，不要改文件内容。
为什么要写这么啰嗦？
因为小白翻车，多半不是软件坏了，是这句话太飘：
「帮我整理一下。」
整理什么？删不删？分哪几类？你确不确认？ 它只能猜。 猜错了，你就觉得「AI 不行」。
先计划，你点头，再执行。确认权跟着你。
打卡：
[ ] 它先给出了步骤计划
[ ] 你看过，点了确认 / 同意执行
[ ] 开始出现执行过程（日志 / 进度 / 桌面动作，以界面为准）
中途要停：找暂停、取消、接管一类按钮。 第一夜宁可停，也不要连环甩「顺便把整个下载文件夹也清了」。

步骤5｜验收（大约 5 分钟）
打开 豆包练习-第一夜，对照：

过关标准再念一遍：
你没用手拖文件；分类完成；清单能给人看。
过了？ 今晚的课结束。 可以关电脑。
没过？ 也别今晚加戏。 把失败截图留着，明天只改一句指令再跑——通常比换软件更快。

第一夜到此为止（加餐选做）
主线绿勾齐了，才看下面。 没齐，跳过。
同夹加一刀：
「只读取其中一份 PDF，出 100 字摘要 + 3 个要点。不要移动文件。」
飞书入口：你公司飞书够新，侧栏也许能看到豆包工作——知道即可，第一夜仍以电脑客户端为准。
安全：练习夹勿塞隐私；对外价格、合同、责任，别只信 AI 生成字（中消协也提醒过类似消费注意）。
同类「会交活」的桌面 Agent 还有别家（比如你可能听过的 WorkBuddy）。 第一夜不测评、不搬家。 你先在一个产品上，亲手摸到「确认 → 文件真的动了」。

今晚打卡清单（复制到备忘录）
[ ] 打开 doubao.com/work，装好电脑版
[ ] 登录成功，能进工作任务
[ ] 建好 豆包练习-第一夜，只放不心疼的杂文件
[ ] 发出「先计划后执行、禁止删除」的整理指令
[ ] 确认计划后执行完成
[ ] 子文件夹 + 清单验收通过
样板房明天再逛。 技能商店、定时任务、连飞书——绿勾齐了再加。
知道什么时候停手，本身就是判断力。

芭提雅，「豆包练习-第一夜」里数了五个小格子，把新品评测页关掉了。
