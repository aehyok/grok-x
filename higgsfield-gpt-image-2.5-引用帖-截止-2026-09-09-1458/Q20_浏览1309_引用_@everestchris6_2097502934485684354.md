## 原文

gpt-image 2.5 is out and it can't get more realistic than this

here's how to generate images like these:

- grab a reference image with the look you want
- describe the scene you want in one rough sentence
- have chatgpt astra turn both into a full json prompt
- the json carries the camera, lighting and colour grading
- run it through gpt-image 2.5 on higgsfield
- save a character you like and reuse it every time

gpt-image 2.5 sunburst and flare are both on higgsfield.
