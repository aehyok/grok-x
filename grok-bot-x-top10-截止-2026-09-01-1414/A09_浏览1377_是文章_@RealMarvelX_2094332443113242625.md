## 正文

Grok Bot 是 xAI 2026 年 8 月 11 日 beta 上线的真产品：不是聊天机器人，而是合上笔记本还在干活的持久 AI 队友花名册。「第二大脑」是让这些队友共享记忆、接到真实工具的那一层，而不是聊天一结束就全忘。文章用一个有文档的例子：整家基于 Whop 的生意通过 Grok Bot 来跑，并落到 Stripe CLI。

### Grok Bot 实际是什么

建在 Grok 上，和 SpaceX 正在收购的 Cursor 联合分发。先是内部原型，xAI 自己的团队拿来做销售、市场、运营、工程，再变成公开产品。你得到的不是一个聊天窗，而是花名册：每个 Bot 是具名、持久、有岗位的 Agent，跑在带浏览器、文件系统、终端的专用云电脑上，你的设备关了它还在干。

这不是凭空出现。xAI 2026 年 7 月给 Grok 加了定时 Automations，再给编码 Agent Grok Build 加大规模并行工作流。Grok Bot 是这些想法收敛成队友式界面的地方。

完整能力：持久云电脑；同一账号上所有 Bot 共享那台电脑、文件和浏览器会话，各有自己的屏幕并行；没有干净连接器时可用电脑使用逛网站（站点仍可能拦自动化或 CAPTCHA）；插件和 MCP；2–6 个 Bot 可进群聊互相交接；skill；例程（日程或事件）；Teach a task（看你演示一遍浏览器流程再起草 skill）；审批（发送、发布、删除、购买、碰生产系统前可要求签字；密码、2FA、CAPTCHA 即使在 Bot 浏览器会话里也留在人手上）。

### 什么让它像「第二大脑」

xAI 从未把某个开关叫 second brain。这个词来自人们怎么用：接到聊天结束后还活着的结构化持久知识系统。多个 Bot 跑同一任务时特别有用——研究者、核验者、写作者——各自人格和角色，共享工作通过群聊或连接文件流动，而不是你手动复制上下文。一种有文档的共享层用 git 原生结构：主分支只读，写走 worktree 或单独分支。这条规则阻止多个 Agent（Grok Bot、Claude Code、Codex 等）抢同一「脑子」时互相覆盖。xAI 也建议重要或变得快的东西去查 live source，别只信 Bot 记得的。

### 怎么设

接近 xAI 自己建议的第一 Bot 定义：短名字、一份活、规则说白。比如 Researcher Bot：只用公开来源、每条重要主张带直接源链接、把已核事实和假设分开、没审绝不对外发布或发送。边界越具体，攒下来的上下文越有用。跨很多外部服务时，Composio 这类插件可一次装上，暴露 1000+ App 的工具发现和执行，OAuth 和 token 刷新集中处理。Bot 只在任务真需要时再请求某个 App。

### 实操：用 Stripe CLI 跑支付

Stripe 给软件生意最常用，官方 CLI 之外还有专门给 Agent 的托管 MCP；docs.stripe.com 任意 URL 加 `.md` 就是给模型直接读的纯文本。

- 从 starter repo 拉起可用 Stripe 环境，立刻拿到 API key，Agent 能在任务中途 bootstrap 隔离可丢弃环境。
- 为买家建客户并开发票。CLI 资源形状一致：create/list/retrieve/update，学会一个就能套下一个。
- 发货前确认 webhook 真的会触发：Agent 从终端开隧道、打真实事件，不用公网 URL 或重新部署。
- 把业务当数据读回来，不是仪表盘截图。同一读模式可到余额、打款、争议。

三步接线：最后一步 `stripe agent setup` 检测你在跑哪个 Agent 客户端，自动配托管 MCP 和维护的 skill 集。无人值守跑用受限 API key，而不是每次交互 OAuth。

### 一次跑多个 Bot

2–6 个 Bot 进群聊，互相传所有权，人不用手动传更新。有人给 Bot 套真实团队成员人设，对齐计划、指定负责人、自动交接，产出完成交付物。每个 Bot 保自己角色和私有上下文，群聊、共享文件、连接的知识库当公共层。多 Bot 并行时，有人接任务跟踪器，让每个 Bot 记下自己在干什么、交给了谁、卡在哪。

### 放着跑之前要知道的三件事

1. 重试应安全：幂等键，避免同一操作因错误重试做两次。
2. 有后果的动作要审批门：汇钱、退款、改生产。密码、2FA、CAPTCHA 设计上留在人手上。
3. 同一账号上的 Bot 不是分开的安全边界。共享同一云电脑，包括文件、浏览器会话、命令行凭证。作用域 API key 限制的是某个已连接工具，不是把一个 Bot 和另一个在同一台机器上隔开。

### 限制

早期 beta。启动时限 macOS、Windows、iPhone；Linux 桌面、Android、iPad 当时没有。访问不免费：SuperGrok Heavy、Cursor Ultra 或合格 Cursor 团队套餐，启动无免费档。live key 没有 dry-run：连真实工具时动作是真的。浏览器自动化有真实限制。重度多 Bot 会很快撞用量上限。

合在一起，人们说的「第二大脑」不是设置菜单里的一个开关，而是持久共享上下文层（每 Bot 私有记忆 + 文件/聊天/交接的公共层）加上像 Stripe CLI 这种 Agent-first 工具：从一句人话到创建客户、收款、测 webhook、把数字当数据读回来。审批门和 scoped key 不是事后加的摩擦，而是今天就能安全把这么多真实世界权限交给 Agent 的原因——在一个仍在找边界的早期 beta 产品里。
