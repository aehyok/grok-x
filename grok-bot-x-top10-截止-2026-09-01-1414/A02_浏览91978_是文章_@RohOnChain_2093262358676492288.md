### 第 1 部分：做市是什么，零售哪里能打

做市是持续报买卖价、吃中间价差。库存风险是陷阱：价格在你报价成交前反向，价差就是噪音。Avellaneda-Stoikov 2008 论文是现代做市基础文本。预约价 `r = s - q · γ · σ² · (T - t)`，最优半价差 `δ = γ · σ² · (T - t) + (2/γ) · ln(1 + γ/κ)`。数学公开，持续跨场所跑的基础设施才是护城河。

零售打不了：美股顶级标的、主要外汇、美国国债 on-the-run，托管机房微秒级，你走券商 API 要 20–100 毫秒。零售能打：永续 DEX（Hyperliquid、dYdX）、预测市场（Polymarket）、Uniswap V3/V4 集中流动性。

### 第 2 部分：Grok Bot 界面层

Grok Bot 是 xAI 的自主 Agent 平台。你创建的每个具名 Bot 共享一台持久云电脑：浏览器、文件系统、终端都在云 VM 上。像在 Slack 给同事发消息。做市台部署六个具名 Bot：

- **报价 Bot**：用 Avellaneda-Stoikov 算预约价和最优价差，每秒写共享报价文件。
- **库存 Bot**：跟踪所有场所仓位，实时改报价 Bot 的库存输入，越界告警风险 Bot。
- **风险 Bot**：硬杀开关，无谈判权。回撤超分配资金 5% 立刻全场所撤报价。
- **对账 Bot**：每 30 秒把成交和预期、场所仓位、内部账对齐。
- **微观结构 Bot**：盯盘口深度、对手做市商报价、价差动态。
- **宏观过滤 Bot**：用 Grok Bot 原生 X 集成盯美联储、特朗普 Truth Social、宏观数据发布，事件触发加宽或撤报价。

六个 Bot 都用自然语言对话，都写到 Grok Bot 云电脑上的共享工作区。运营改动走对话，没有配置文件、没有重新部署、没有上下文丢失。
