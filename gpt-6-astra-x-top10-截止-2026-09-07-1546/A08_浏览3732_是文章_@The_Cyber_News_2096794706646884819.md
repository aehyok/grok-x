## 正文

本期网络安全周报覆盖关键 0-day、国家级路由器入侵、新兴自主 AI 攻击路径，以及重大云身份事件。下面按原文条目译出。

CrowdStrike Falcon 传感器提权主张。化名 Nightmare-Eclipse 的研究者发布名为 FalconFlank 的概念验证，声称针对 Windows 11 / Windows Server 2025 上 Phase 3 Optimal Protection 的 Falcon Sensor 本地提权，利用清除恶意 Office 宏时的修复流程。CrowdStrike 称正在调查，建议客户关闭「Microsoft Office File Suspicious Macro Removal」Windows 策略，同时保留云反恶意软件。端点代理以高权限隔离和改文件，理论上本地低权用户可能拿到 SYSTEM。请看客户门户里的 FalconFlank Tech Alert。

Google Chrome V8 在野 0-day。紧急桌面更新修复正在被利用的高危 V8 类型混淆 CVE-2026-85046，报告者 Salvatore Gulizia。类型混淆会把为一种对象分配的内存当成另一种访问，通向内存损坏或浏览器进程内任意代码执行。稳定版打到 152.0.7977.82/.83（Win/macOS）和 152.0.7977.82（Linux）。利用通常要骗用户打开钓鱼、恶意广告或被黑站点上的特制页面。企业应尽快推浏览器更新。

Magento / Adobe Commerce 的 StyleSmuggler 0-day。Sansec 发现未认证远程代码执行，影响含 2.4.9 在内的受支持版本，已有打过补丁的商家中招。攻击者在未认证 GraphQL 查询的 styles 属性里把 PHP 塞进内部日志和报告文件。Magento 内部渲染标准支付失败通知邮件时自动触发，收件人不用点。随后投放器轮询 PHP 执行函数，部署伪装成合法内核线程的持久 Rust 二进制。官方补丁尚未发布，可考虑暂时关掉 GraphQL，并收紧进程执行权限。

VMware Workstation / Fusion 主机代码执行。Broadcom 公告 VMSA-2026-0007：访客沙箱可逃逸。最重的 CVE-2026-59346，CVSS 9.3，VMXNET3 虚拟网卡整数溢出，访客里有本地管理权限即可在宿主机执行任意代码。第二条 CVE-2026-59347，共享文件夹 HGFS 栈缓冲溢出，CVSS 8.1。26H1u1 已修，无功能绕过。用虚拟化沙箱引爆恶意软件的团队必须立刻打补丁。

HardBreacher PoC 针对卡巴斯基。MSNightmare 公开仓库，声称 Kaspersky Endpoint Security 14.0.0.504（Win11）未确认本地提权，通过操作用户界面在受保护的 System32 里写任意 DLL。无 CVE、无厂商正式确认，作者称不稳定、常需重启和多次尝试。在有结论前请盯厂商公告，并查系统目录里异常建文件。

OpenAI GPT-6 Astra 发现 0-day。OpenAI 发布前沿模型 GPT-6 Astra，在授权攻防基准中展示：能发现软件 0-day 并构造可用的概念验证利用。ExploitBench 得分 100%，电脑操作和调试能力很强。Astra 能检查复杂代码库、与命令行环境交互，执行失败后迭代修改利用。自动化找洞有利于加快补丁，也带来利用工程被摊平的双用途担忧。OpenAI 称安全控制使模型在蜜罐评估中没有越过授权边界。前沿模型获得代理自主性后，防御必须适应以机器速度运转的对手工具。

自主 AI 代理打穿企业网。Palo Alto Networks Unit 42 的应急响应：对手用自主 AI 代理在不到 10 小时内打进企业网，把 50 多项 MITRE ATT&CK 技术收进自动循环，并不依赖新型 0-day。工作流自动做内网侦察、在代码仓库里找秘密、从集中密钥管理器收割主凭证。代理还攻 CI/CD 抽云密钥，试图往 Terraform 模板塞后门，并生成完整技术审计当勒索筹码。调查人员看到并行代理会话之间结构化 Markdown 交接，是代理编排的清晰痕迹。防御必须对基础设施仓库做严格代码审查，并建立自动吊销凭证的机制。
