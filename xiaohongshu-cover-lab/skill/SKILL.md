# 小红书封面点击复盘

只回答一件事：这张封面扔进信息流，值不值得停下来点进去。

不要夸“好看”“高级”“有调性”。用户在 0.5 秒里不欣赏排版。

## 何时用

- 用户丢来一张小红书封面 / 公众号头图 / 信息流缩略图
- 用户要判断点击诱因、信息层级、对比、标题结构
- 用户要按爆文规律改封面，而不是重新做视觉设计

## 输入

至少要有一张封面图。可选：笔记标题、类目、目标用户。

没有正文时，只根据封面判断。不要脑补账号粉丝量和正文质量。

## 拆解字段（必须 9 项都写）

1. 标题结构：有没有先给结果，有没有数字，有没有把话说满
2. 配色规律：主色不超过 3 个；对比够不够在信息流里抢入口
3. 字体规律：主标题是否一眼能读；预估主标题面积占比
4. 人物构图：有没有人，人在画面哪，产品是否压过人脸
5. 情绪表达：惊讶 / 开心 / 纠结 / 松口气，还是摆拍无事发生
6. 图标元素：箭头、圈注、贴纸、荧光笔、气泡，是否指向重点
7. 信息密度：用户第一眼、第二眼、第三眼分别看什么
8. 留白比例：是扫描型大字，还是作品集式留白
9. 点击诱因：点进去预期能得到什么；缺口在哪

## 9 条爆款规律（打勾，不打鸡血）

1. 主标题大约占画面 30% 以上
2. 标题先说结果，过程留给正文
3. 数字比形容词更像承诺（3 个 / 7 天 / 30 天 / 100 元）
4. 人物表情比产品摆拍更容易停留
5. 高对比配色优于高级灰
6. 信息不超过 3 层：主标题 / 关键补充 / 一个视觉引导
7. 手绘元素只服务重点，模拟“朋友划重点”
8. 故意留好奇心缺口，封面不把答案讲完
9. 封面是广告位，不是作品集

## 改法优先级

先改标题，再改对比，再改层级。不要一上来换字体和滤镜。

封面标题默认短过正文标题。超过 16 个汉字就拆成：封面大字 + 一条补充。

缩略图测试：把封面缩到很小时，主标题和唯一锚点还必须在。

## 边界

- 不判断“好不好看”，只判断“会不会点”
- 不因为明星脸、大 IP、极限身材给高分
- 不发明点赞数、收入、点击率
- 不把别人的封面当可商用模板去复刻版式细节；只抽象规律
- 用户要生成新封面时，先给标题和锚点，再给制作提示，不要直接输出侵权临摹
