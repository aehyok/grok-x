## 正文

codex tip: set up an automation to keep your skills updated. 

instead of letting your codex skill sit static, get it to update itself weekly based on your usage patterns, so it can reflect more of the workflow changes.

prompt: "set up a weekly automation that reviews the 7 days of my accessible codex session history and logs, then automatically update the skill named [skill name] and its skill.md to reflect my current workflow.

only make changes supported by repeated evidence. preserve useful existing instructions, avoid unrelated rewrites, and update only this skill file. do not include secrets or personal data. after applying the changes, report a concise summary.  if no meaningful changes are found, leave the file unchanged and report that."

this way your skill evolves alongside your workflow instead of going stale the moment your process changes.

(not a new concept if you've been using codex for a while, just in case some of you didn't know it)
