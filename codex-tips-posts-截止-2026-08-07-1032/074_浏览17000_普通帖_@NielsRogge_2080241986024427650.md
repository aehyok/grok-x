## 正文

For Codex users, here are some tips and tricks I use all the time  

- Press both ⌘ buttons; this captures your screen, which gets sent to Codex directly. The feature is called AppShots, super useful to debug frontend issues (see below)  

- Use "meta" features. You can ask Codex about other threads, or even ask it to create new threads in goal mode. Ask it about previous chats you had, and it'll find them, or change its config  

-  Do not use the built-in plan mode; instead, just ask Codex to write a PLAN.md and iterate on it. Use the /grill-me skill by @mattpocockuk after it creates the first plan, then tell it to update it after each question  

- When you are prompting Codex a lot of times in the same way, turn it into a reusable Skill. Ask it to turn the task into a skill using the /skill-creator Skill  

- Use /goal mode for long-running, async tasks. Usually results in more thorough results compared to non-goal mode
