🎉 Matt 大神的 Skills v1.2 正式发布！

作为我电脑里大浪淘沙后、为数不多舍不得删的宝藏 Skill（官方已突破 1350 万次下载！），这次又带来了重大更新

新增核心
- 全量文档：涵盖核心流程与排错指南，补齐最后一块短板
- Claude 插件：支持通过 Claude 官方市场一键安装
- Codex 支持：配置 agents/openai.yaml 即可无缝接入

技能体验优化
- /grilling  升级为轮次提问，对话体验更自然
- /prototype  改用 HTML 替代 TUI，更好分享、功能更强
- /writing-for-agents  专为优化 Agent 读取内容（提示词、文档等）而重命名

✨ 全新技能加入
- /wizard  去繁琐配置，让 Agent 自动构建 TUI 向导带你飞
- /to-questionnaire  被问题卡住？一键转换为结构化文档，方便会议同步与需求整理
- /wait-what  看不懂模型黑话？用行业语言重新聚焦，通过 ASD-STE100 极简呈现

传送门👉🏻：https://www.aihero.dev/skills
