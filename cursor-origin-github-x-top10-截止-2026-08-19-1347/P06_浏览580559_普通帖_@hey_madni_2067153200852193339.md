iOS 测试版现在就在 TestFlight 上（目前已满）

**2/ Origin**

一个直接的 GitHub 竞品

专门为 Agent 时代打造

口号：「Agent 时代的 git forge」

**Origin 实际在干什么**

- 自动解决合并冲突

Graphite → stacked PR 和代码审查  
Origin → 底下的托管和合并

从写代码到上线，每一步 Cursor 都握在手里

写代码 → Cursor IDE

跑 Agent → 后台 + 云端 Agent  
审查 → Graphite  
托管和合并 → Origin

三年前他们还只是 VS Code 分支
