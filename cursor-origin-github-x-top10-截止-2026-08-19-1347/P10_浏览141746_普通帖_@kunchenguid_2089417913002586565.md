## 正文

其实没人在做真正的 GitHub 替代品。

Cursor 的 Origin 上线刚把这点坐实了——他们只在替代 GitHub 的**付费版**，因为钱在那里。

如果大家都去抢付费源代码托管，把这块从 GitHub 抽走，GitHub 就养不起开源生态了。

我希望在那之前，我们能想出一条可行的替代路。

## 原文

no one is actually building a Github replacement

cursor's origin launch just confirmed this - they are only building a replacement for the _paid_ version of Github, because that's where the money is

if everyone goes after the paid source control business and take that away from Github, Github will not be able to sustain the open source ecosystem

i hope we figure out a viable alternative before that happens..
