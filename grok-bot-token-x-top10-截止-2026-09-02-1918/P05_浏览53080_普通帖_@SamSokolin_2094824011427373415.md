## 正文

让 Grok Bot 在网页里反复点同一套点击，会烧掉大量 token。作者（SpaceXAI，Grok Bot 工程）觉得最能拉长用量的办法：让 Bot 把昂贵的浏览器任务反解成脚本。

先让它在一次 computer-use 里抓网络请求；下次跳过 UI，用同一套鉴权直接打 API。

附带好处：比让 Bot 在 GUI 里点来点去快得多。

评论里有人指 Hermes Agent 同类 skill：https://github.com/NousResearch/hermes-agent/blob/main/optional-skills/web-development/har-derived-api-client/SKILL.md

## 原文

Having Grok Bot redo the same clicks in a web app burns a lot of tokens. One of the best ways I've found to stretch your usage is asking @bot to reverse engineer expensive browser use tasks into scripts!

Have it capture the network requests from a computer-use run once. Next time, skip the UI and hit the APIs directly with the same auth.

This also has the added benefit of being way faster than having Bot click around in a GUI!
