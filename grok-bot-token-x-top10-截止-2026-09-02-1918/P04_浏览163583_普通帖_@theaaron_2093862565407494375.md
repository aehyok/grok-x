## 正文

我喜欢 Grok Bot，不喜欢它的速率限制。

一个简单办法：把你的编码 Agent 装进 Grok Bot 的虚拟机——Codex、Cursor、Grok Build、Antigravity 等。再装 Herdr 来管这些 CLI 会话。

然后给 Bot 一条规则：只要不是闲聊，就走 Herdr + CLI。

这样 Grok Bot 的额度只花在协调和写提示上，编码本身走 Cursor / Grok Build 自己的池。两边叠着花，没那么快撞墙。

YouTube 版：https://www.youtube.com/watch?v=5YWzevU2d1Q

作者补充：Herdr 是 @jethrojones 教的。即便编码会话大多在云端跑，Herdr 对「让 Agent 管住自己的编码会话」仍然很有用。
