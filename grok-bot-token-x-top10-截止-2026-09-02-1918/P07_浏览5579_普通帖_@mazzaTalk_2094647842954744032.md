## 原文

Grok Bot 额度掉得很快。真正该用的是它那台云电脑。

做法是：把 Codex、Cursor、Grok Build 这些 CLI 直接装进 Bot 的虚拟机，再用 Herdr 把这些 agent 会话管起来。然后给 Bot 一条规则：只要不是闲聊，就走 Herdr + CLI，别自己上手改代码。

这样 Grok Bot 的额度只花在拆任务、盯进度、卡住了问我。编码走 Cursor / Codex 自己的额度，两边叠着花，没那么快撞墙。Herdr 是后台挂着的，电脑合上、网络断了，agent 也还在跑。

我自己项目多、任务类型也不一样，本来就要不同模型和 agent 搭配。Bot 当项目经理，Herdr 管这群 CLI，电脑可以合上，活还在云上跑。

有Gro Bot 的可以装一下 Herdr 试试。别把额度拿去一行行改代码。
