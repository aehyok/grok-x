## 正文

RUNTA FrontierHarness v1.0（2026-09-01）：模型锁 Kimi K3，9 个 harness、12 种组态、30 题、360 格冷启动。通过率 50.0%–66.7%，单次通过成本 $1.05–$18.34。

DSH 跑了四种 profile：

| 组态 | 通过率 | 单次通过成本 |
|---|---:|---:|
| DSH Creator | 63.3% | $3.28 |
| DSH Standard | 60.0% | $3.46 |
| DSH PTC | 60.0% | $4.58 |
| DSH Minimal | 56.7% | $4.72（中位最快 5 分 41 秒） |

Claude Code 也是 63.3%，但单次通过 $18.34，约为 DSH Creator 的 5.6 倍。Codex 通过率最高 66.7%、$3.47。同厂 DSH 四种 profile 之间，通过率差 6.6 点、成本差 1.4 倍，已经接近不同 harness 之间的差距。

失败也花钱：DSH PTC 超时失败 $12.95，比六个过关组还贵。

## 原文

https://runta.com/blog/introducing-frontierharness-eval/
2026 年 9 月 1 日，Shilin Zhu、Shiqi Mei 在 RUNTA 部落格發布 FrontierHarness v1.0。同一套軟體開發跟終端任務，只換 Harness，帳單、通過率、牆上時間差很大。作者認為，差在 Harness 跟模型怎麼配。模型單獨比較強，解釋不了這組帳單。

他們把模型、題目、執行環境一起鎖死。模型是 Kimi K3，統一走 Fireworks。九個 Harness 中間只放一個 gateway，同時講 OpenAI Responses 跟 Anthropic Messages，各家用自己習慣的協定，打到同一顆 K3。場上 9 個 Harness、12 種組態、30 題（21 題 Terminal-Bench、9 題 DeepSWE），一共 360 格。一格只跑一次。每次都是冷啟動，從同一份 golden checkpoint 還原到記憶體狀態，連磁碟內容跟記憶體都對齊。正式評測前不跑真題。作者寫，debug 會把隱性前綴快取暖幾個小時。

360 格裡 209 過、151 不過。場上通過率 58.1%，權重後的快取命中 92.4%。12 種組態通過率從 50.0% 到 66.7%，只差 17 點；單次完成成本從 1.05 美元到 18.34 美元。

依通過率排，最高是 Codex：66.7%，單次通過成本 3.47 美元，快取命中 88.0%，中位時間 6 分 43 秒。DSH Creator 63.3%、3.28 美元。Claude Code 同樣 63.3%，單次通過成本卻是 18.34 美元，快取命中 67.8%，中位 9 分 38 秒，相對 DSH Creator 貴 5.6 倍。Pi 60.0%、2.43 美元。DSH Standard 60.0%、3.46 美元。DSH PTC 60.0%、4.58 美元。Kimi Code 56.7%、3.65 美元。DSH Minimal 56.7%、4.72 美元，中位最快 5 分 41 秒。Oh My Pi 56.7%、4.75 美元。Exo 最便宜，1.05 美元、通過率 53.3%。Hermes 跟 OpenCode 都是 50.0%，單次通過成本分別是 2.90 美元跟 3.24 美元。DSH 是 DeepSeek Harness，這次跑四種預設檔：standard、minimal、creator、code(PTC)。

過關跟過得便宜，這次被拆開了
Claude Code 跟 DSH Creator 都過 19 題。一邊單次通過 3.28 美元，另一邊 18.34 美元。過關跟過得便宜，在這組數字裡走的是兩條線。Codex 跟 DSH Creator 通過率在最上段，花費又靠近場中位，兩件事可以同時做到。

快取命中別直接當成成本。這次付的是步驟跟 token；快取只改單價。一次走很長、最後失敗的軌跡，就算快取命中很高，仍可能比一次短、幾乎沒打到快取的還貴。

同廠也沒主場優勢。Kimi Code 跟 Kimi K3 出自同一間實驗室，通過率 56.7%，並列第七，成本也在場中段。它的 kimi provider 打這次的 gateway 回 404，後來改成 anthropic、走 Messages。串流輸出沒帶用量，作者從 session 線上的 usage.record 補回來。快取命中中位 88.0%，跟場上最好的一檔並列，但沒換成更高通過率或更低成本。

選 K3，是不想讓 Claude Code 或 Codex 帶著自家模型進場。K3 有公開的 token 價，快取是隱性前綴快取。各家跟這顆模型合不合的問題還在，只是起點比較中性。Kimi Code 理論上最該佔便宜，這次沒佔到。

中位格子跟權重後的帳單
排行榜上的快取命中是中位數。Claude Code 中位格子 67.8%，跟 Codex 的 88.0% 比，大約差 1.3 倍。權重後的快取命中卻掉到 25.0%。場上其他 Harness 權重後落在 91.6% 到 99.1%。中位跟權重差 2.7 倍。儀表板畫的是中位數；把輸入 token 帳單推上去的，是權重後那個數字。

權重被最貴那一格拉歪。Claude Code 最貴那題 64.36 美元，快取命中 15.7%。19 個成功格子裡，三格吃掉 88% 的 token；其中 python-statemachine-state-data-scoping 一題就佔 68%，輸入 24.6M token，命中 15.7%。作者說，25.0% 這個權重後數字，多半是這一格特別大的結果，不代表 Claude Code 的典型行為。

作者傾向往搭配上找原因。Claude Code 是為 Anthropic 的顯式 cache-control 設計的；K3 暴露的是隱性前綴快取，同一套快取策略不一定搬得過去。這是整套 Harness、模型、gateway 組態的性質，帳不能先算到 Claude Code 單獨頭上。

軌跡裡，同一段只往後追加的對話，有的 call 100% 命中，有的幾乎只打到系統 prompt 那 18.4K。一次封存的 session 裡，大約五次才有一次打滿前綴；中間很多次讀到的快取卡在系統 prompt 大小，後面長出來的對話按新價計。呼叫之間這樣跳，很難說成某一個 Harness 自己寫死的策略，比較像隱性前綴快取在場上自己跳。

18.34 美元跟 64.36 美元，講的是這次測到的整套組態。Claude Code 沒有被單獨拆出來算。把 Harness、模型、gateway 拆開，是 v1.1 清單上的第一件事。

同一題過關，收據可以差二十六倍
datacurve/python-statemachine-state-data-scoping 是對 fgmacedo/python-statemachine 某個釘死 commit 的功能需求。DeepSWE 官方通過率 38%，歷史中位 117 步。要動到 metaclass、callback 注入、歷史還原、pickling、SCXML parser、圖形渲染，還得讓原有測試維持綠燈。12 組裡 7 組過。

Pi 過了：2.50 美元、90 輪、快取 98.2%、39 分鐘。Claude Code 也過了：64.36 美元、381 輪、15.7%、60 分鐘。價錢差 26 倍。步驟更多，每一步又更貴。通過或失敗那一欄看不見這兩件事。

沒過的格子，帳單照樣進來。Exo 踩到 51 步上限，失敗花 1.46 美元。DSH PTC 逾時失敗，花 12.95 美元，比六個過關的還貴。DSH Creator 逾時失敗 3.88 美元，DSH Minimal 過關 10.49 美元；同一個 Harness、同一模型、同一執行環境，只換預設檔，節奏跟結果都變了。OpenCode 逾時、0 輪，成本是 n/a。

失敗也要花錢。只算成功的成本，會把帳單的大半藏起來。

差距掛在搭配上
v1.0 只涵蓋軟體開發跟終端任務，還不能拿去概括其他 Agent 工作。Harness 按原廠出貨跑，不改內部。像 Claude Code 這種對快取很有主見的，作者沒有進去改命中率，也沒有為了跨 gateway 把快取策略拉齊。帳上的成本差，反映的是整套出貨組態。不能說如果每家都為 K3 的快取調過，差距還剩多少。

通過率差 17 點，單次通過成本差 17 倍。Codex 最穩：通過率最高，成本靠近場中位的 3.47 美元。同一份工作要跑很多次、token 會疊上去，選 Pi；最難那題它跟 Codex 交出同一份過關，90 輪、2.50 美元，對上 Codex 的 187 輪、5.97 美元。Exo 單次完成最便宜，1.05 美元，部分因為它會早停；最難那題撞上 51 步上限，失敗只花 1.46 美元，別人還在繼續燒。這次沒測重試。失敗得便宜，才比較適合拿去重試。

DSH 四種預設檔，通過率差 6.6 點、成本差 1.4 倍，已經接近不同 Harness 之間的差距。prompt、工具迴圈、快取策略，都掛在這組配對上。為某一家的快取規則調過的 Harness，在那邊看起來省，換規則就可能變貴。v1.0 把模型、題目、執行環境鎖死，這層差才看得清楚。
