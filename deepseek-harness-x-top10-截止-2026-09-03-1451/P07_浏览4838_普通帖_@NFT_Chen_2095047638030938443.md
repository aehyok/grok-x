DeepSeek Harness v0.1.2-alpha.4：

1. 父 Agent 和可持续子 Agent 可通过 send_message 互发后续消息，不再单向 report
2. 自定义模型发现复用 Profile 请求头，模型目录可搜索筛选
3. UI：圆角、描边、轮次导航、投影
4. 超长会话：流式回复/布局/导航预览渲染开销下降
5. Python SDK / Headless / ACP / 自定义 Profile 默认带 web_fetch
6. Web PTC Mode 默认不再给模型塞通用 workflow 工具
7. 会话事件接口改成按需读取的 seq、eventAt()、snapshotEvents()
8. SessionSeq 和 SessionLogOffset 强类型区分，插件要兼容

Release：https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.2-alpha.4

## 原文

🚨DeepSeek Harness 又更新了！v0.1.2-alpha.4 真的是一天一更、小步快跑 🐋

这次更新别只当“修修界面”，几个点挺关键：
1️⃣父子 Agent 能双向对话了：父 Agent 和可持续子 Agent 可通过 send_message 互发后续消息，不再是单向 report
2️⃣自定义模型发现会复用 Profile 请求头，模型目录支持搜索和筛选
3️⃣UI 更精致：圆角、描边、轮次导航、投影都优化了
4️⃣超长会话更跟得上：流式回复、布局、导航预览的渲染开销明显下降
5️⃣Python SDK / Headless / ACP / 自定义 Profile 默认带上 web_fetch
6️⃣Web PTC Mode 默认不再给模型塞通用 workflow 工具
7️⃣会话事件接口变了：https://t.co/UXBCYwCkEU 换成按需读取的 seq、eventAt()、snapshotEvents()
8SessionSeq 和 SessionLogOffset 强类型区分，插件党注意兼容

之前装过插件的，建议升级后先自查一遍，别等跑崩再改。

Release：https://t.co/GFEagt7HHN
