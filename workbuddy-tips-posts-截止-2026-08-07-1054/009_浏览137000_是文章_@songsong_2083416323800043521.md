# Everybody！WorkBuddy 教程来了

装完 WorkBuddy 的第一个星期，我干了件丢人的事：把上个月的报销单甩给它，打了四个字，帮我整理。

它整理得挺快。表打开一看，金额那一列有含税的有不含税的，时间格式一半是七月一半是 07-01，还有几张发票它自己判断"可能重复"，直接没列进去。我当下的反应是：就这？

后来研究才明白，我当时要求了个寂寞。金额按什么口径、时间用哪种格式、拿不准的那几张怎么办，我都没有清楚的要求。打四个字就等一张能直接报上去的表，我是天真，它是无邪

没有要求，它只能猜。而猜的时候一定挑最省事的

说了半天 那WorkBuddy是啥呢？它是腾讯云今年3月上线的AI办公助手，装在你自己的电脑上，能翻你的文件、做表格、写文档，也能连上你的邮箱替你发邮件

既然它能干这么多事情，你就不能还停在只跟它聊天的阶段。你要把它当成你的牛马，你要管它，它才能给你挤奶。

那牛马怎么管、活怎么交代、交上来的东西凭什么信、怎么让他记住规矩、什么时候才敢撒手，我一步一步教你。装完就放着的、试过一次觉得不行的、每天在用又总觉得没使上劲的，你就给我往下看，一看一个不吱声。

先从你现在怎么用它开始。

## 第1章 WorkBuddy能干什么、怎么装、第一个活怎么派

比起 Claude Code和Codex ，workbuddy 不需要一些有的没的，没有门槛，直接安装即用。

首先官网找到下载页，按你是Windows还是Mac下对应的包，装完打开登录就能用。

装的时候有四点注意。第一，只从官网下，第三方安装包别碰。第二，C盘剩不到十个G的，先把安装路径改到别的盘，它跑起来模型缓存和过程文件都占地方。第三，安装路径和以后放活儿的文件夹，都别用中文名。第四，装的时候先把360这类关掉，免得它把人家的模块当病毒杀了。

钱先不用掏。官网给免费体验版的口径是每月500积分。注册时另外还会到一笔新人积分，先拿这些把这篇里的活试一遍妥妥够。

几个栗子：

- 桌面乱成一锅粥，让它按类型归位，图片进图片夹、文档进文档夹
- 会议录音甩过去，转文字、提行动项和责任人、生成纪要
- 十几个Excel合并成总表，算各部门环比，顺手出一张柱状图
- 一份报告变成5页PPT，配图建议写在备注里
但是创意的活不能靠它。让它给新品起个名、写条小红书文案，内容规整、正确、却无趣。

要拿捏分寸的活也别交。一封催供应商回款的邮件，它写得生硬，该软的地方软不下来，该硬的地方又硬不起来。

规则明确、你自己心里有标准的重复活，才是它的舒适区，交给它 又快又稳。

装完跑个试试

第一步，布置一个工作区。 先在电脑上新建一个文件夹，比如 D:\试一下，把你要处理的文件复制一份丢进去。是复制，别把原件搬过去。回到WorkBuddy点左上角的新建任务，输入框底下有个选择工作空间，点开选打开本地文件夹，指到刚才那个目录。它就知道去哪儿翻料、把东西存哪儿了。

```
验收标准：
首页每个数我要能从原始表里一步步加回来；
同比环比用同一套算法；
每个结论后面注明是从哪张表哪一列看出来的；
证据不够的写待核实，别替我推测。
```

第二步，权限保持默认，别急着放开。 工作空间旁边就是默认权限，别动它。默认状态下，它要删你的文件、要跑命令，都会先弹一句问你，啰嗦，但是安全呐。输入框右下那个Auto是模型，也先别管，它会按任务难易自己挑。

第三步，把要求一次说全。 这样说：

把 D:\试一下 里的Word文档全部转成PDF，按"日期-文件名"重命名，原文件别删别改，转完告诉我一共几份

跑的中间它会弹出来问你能不能动某个文件，看清楚再点同意。跑完结果就 在D:\试一下 文件夹下。

一次跑通你就有感觉了：跟你交代一个新来的人一模一样。指哪打哪，不过你没说的，它就自己擅自做主了。

在复制件上擅自做主可还行，但是哪天它擅自动了你正在用的客户表，到时候你就想刀它了。这时候就用到它的几个模式了。

## 第2章 默认模式、计划、仅问答，什么时候开哪个

输入框里有个加号菜单，点开有个模式，展开你会看到一句"当前为默认模式"，底下两个开关，计划Plan和仅问答Ask，都是关着的。

两个都不开，就是默认模式。 它直接上手干：读你的文件、改文件、生成文档表格PPT、跑命令，一路做到交货。日常派活就用这个，什么都不用改。

打开计划Plan，它先给方案。 复杂的先把要走的几步列出来给你看，你确认它在继续，觉得不对就让它改。新手必守一条，不要无脑点执行，自己把关，后面会省掉一大堆反工。

打开仅问答Ask，它就动动嘴皮子。 它一个文件都不会碰，写文案、查资料、翻译，给你文字结果。简单问题就用它，省积分，也省得它手欠去动你的文件。

小总结：默认是手快眼快，说完直接上手；计划是想清楚再动的，先给方案等你点头；仅问答是嘴碎的，只说不做。一句口诀，动脑的事先开计划，动手的事默认干。

权限跟模式分开管。 模式管怎么干活，权限管动手之前要不要问你。输入框底部那个默认权限，保持默认就行，它要删你的文件、要跑命令，都会先弹一句提示，安全度高。如果点开允许完全访问，它就不问了，自己觉得该删删，删错了也不管。

为什么不能图省事一路默认干到底呢？因为往后每一步都建在前一步上面，方案错了后面全得重来。所以最好先开着计划多花五分钟，后面能省你两个小时。

新手记一条：别急着开完全访问。先用默认权限跑上十来趟，每次弹窗都看一眼它要动什么，你慢慢就摸清它哪些判断靠谱、哪些爱自作主张。如果要放开，也别在放着合同、财务、客户资料的那些文件夹里放。

牛马也得有张桌子。刚才那个 D:\试一下 就是它的桌子，那这桌子要怎么摆呢？

## 第3章 工作空间怎么建、文件怎么放、项目和对话怎么分

前面设置的工作空间就是这张桌子，workbuddy只在这个文件夹里翻东西、也只往这里头存。里面有什么，它就只能看见什么。

所以空间里别乱堆。这次用得着的放进去，不相干的别放。你要是把三个版本的报价单一起丢进去，如果不明确告诉它，它大概率不会抓最新的。

三个习惯，避掉大部分不可逆事故

一件工作对应一个空间。 不要把不同客户、不同项目、不同选题混在一个文件夹里。它的上下文能力再强，也最好不要去污染。

正式文件先放副本。 尤其是表格、合同、图片库、客户资料。让它处理副本，看结果对不对，再决定要不要迁到正式目录。这一个习惯能避掉一大批改坏了没法退回的事故。

产物要分层保存。 别只留一个最终版。至少留着原材料、过程稿、公开稿、图片、发布记录和复盘。你以后要复用方法、整理案例、训练自己的技能包，都得靠这些过程材料。

一套能直接抄的目录

不用自己设计，照这个建就行，放D盘：

```
根据 D:\交付\季度报告.docx 做一份5页PPT，科技风。
每页只讲一件事，数据全部引用报告里的原数别自己造。
配图建议写在备注里，别插占位图。
存成 D:\交付\季度汇报.pptx。
做完把每页对应报告的哪一节列给我。
```

每个文件夹只负责一件事。整套流程六个动作：建文件夹，放个人资料，接进WorkBuddy，跑通一个任务，把常用要求固化成模板，最后设自动化。

你不用一天把所有功能学完。先把一套能用的工作台跑通，成就感不就来了么

干一次就完的用任务，要干几个月的用项目

点新建项目。必填的只有一个项目名称，限15个字。别的几栏都能空着，但有一栏最好别空，叫指令。

指令这栏，写的是你一次性交代清楚的规矩。 填在这儿的话，以后这个项目里每建一个新任务，它自动带着，你不用再讲第二遍。

举个栗子：

```
读 D:\会议\0320产品评审.m4a，转成文字再提炼成纪要。
我要每个议题的结论、责任人、截止日期，有争议的单独标出来。
原始录音别动，听不清的地方写待确认，别替我猜。
结果存成 D:\会议\0320纪要.docx。
做完告诉我一共几个议题、几处待确认。
```

第一次不用整全。用着用着，哪里卡，哪里总犯错，回来往指令里补一条就是了。

下面还有三栏，连接器、专家、技能，都写着可选，点加号添加。 配一次这个项目通用，以后建任务不用再挑。

懒得自己想的，指令右上角有个选择模板。 项目页上也直接列着五个现成的：产品需求全流程、市场调研与竞品分析、团队知识库、项目交付、Bug跟踪测试验收。挑一个，几栏自动给你填好，你再照自己的活改。有一点注意，弹窗底下那行小字写着切换模版会覆盖当前编辑内容，所以先挑模板再写你自己的话。

## 第4章 积分怎么算、一次任务烧多少、怎么省、各档多少钱

WorkBuddy要花积分，每做一次任务都按积分结算，免费体验版每月500积分，我注册的时候还给2000。但是用起来的时候积分确实烧得太快啦。怎么烧的的呢，往下看

先看模型。刚进去一般是自动模型，它按任务难易自动派活给不同的大模型。

你也能自己指定，列表里是国产主流那几个：DeepSeek、GLM、Kimi、MiniMax。现在Hy3限时免费。在8🈷5号之前可以无限用。

```
每天早上9点读 D:\数据\前一日.xlsx，生成一页日报，通过企业微信发给我。
当天文件要是没有，直接告诉我没有，别拿前一天的顶上。
日报同时存一份到 D:\日报，文件名带日期。
正文第一行写清数据取自哪个文件。
```

重点看模型名后面那个倍数，那是积分消耗倍数。自动是1倍，看到0.57X就是打对折的意思。

真正烧掉的其实是token。积分只是用于便于理解的。
我举个栗子 ，我让它给我出了一份公众号运营优化方案，auto 消耗了60多个积分

所以大概就对消耗积分有个印象。怎样省积分就以下6条。

- 简单问题别开Plan，用Ask就行
- 想好了再发，别拿它当草稿本一句句说
- 日常挑倍数低的，复杂推理再上贵的
- 大任务拆成小步逐个跑，别让一次任务又臭又长
- 重复的活设成定时任务，别手动一遍遍触发
- 重活新开对话。一个对话聊到几十轮，前面那些话每次都要重算一遍
但是方向没定就让它直接动手，最耗，所以需求方向永远是第一位。

再说价格。2026年7月起个人版分成四档：体验版免费，每月500积分；标准版99元一个月，实得4000（2000基础加2000限时加赠）；高级版199元，实得9000（4000加5000）；旗舰版999元，实得50000（20000加30000）。连续包月7折，年付再叠8折。

还有三条隐藏规则：

- 积分当月有效，不结转。 这个月没用完的，下个月不认。加赠那部分更短，自到账日起1个月内有效。
- 扣减按到期时间排队。 系统优先扣最先到期的那批；到期时间一样，先扣基础积分，再扣赠送的。
- 订阅一到期，账户额度直接掉回体验版那500。
所以别囤积分，也别为了"攒着以后大干一场"续费。如果有大把积分，使劲蹬吧你就。

模型选对了、积分也会用了，可它交上来的活你不满意？可能是你指令不对。

## 第5章 一句指令要交代的六件事，附10条能直接抄的

你给的活越模糊，它交付的就越离谱。
先看差别有多大。

反面，帮我把上次的会议纪要整理一下。它只能给你个通用糊弄版。

正面，把 D:/会议纪要/0320产品评审.docx 里的内容整理成清单，每个议题给结论、对应责任人和截止日期，有争议的标出来，用表格输出。它能一步到位就给你个完美交付。

“我要有这功夫 我还用你？”这也是我开始的想法，但你算另一笔账：第一句话发出去，三十秒它给你一坨东西，你花二十分钟看完发现没法用，重发，再花二十分钟。第二句话写九十秒，一次过。

四十分钟，九十秒。咋想是不是咋划算。来吧，教你咋写出来。

一句能执行的活，要交代六件事

你把活交给一个新来的同事，会说清楚材料在哪、要什么成品、哪些底线不能碰、大概按什么步骤、做完放哪、怎么算做好了。所以你就把它当成你新同事就得了。

官方给了一个公式，做什么+有什么+怎么样。这个公式没错，但太粗，我把它拆细成六个字段。

来拿件真事演一遍。每个月报销的发票，散在几个邮箱里，一张张下载、一张张登记时间和金额，然后整理，想想这付出的时间和精力。怎么做？

```
把 D:\资料 里所有Word文档转成PDF，文件名按"日期-原文件名"重命名。
原Word一份都别删别改，加密打不开的单独列出来别偷偷跳过。
PDF全存到 D:\资料\PDF。
做完告诉我转了几份、几份没转成、分别卡在哪。
```

六行，九十秒写完。

但是你要是漏了某一个字段，它不会空着，它会自己补上，咋补的呢

这不只是WorkBuddy的问题。你想想你带过的实习生：交代活的时候漏了验收标准，他是不是也会糊弄一下就完事了。但是实习生会问"老板你说的格式是什么意思"，AI不会。它直接填，而且用最省事的答案。管理学家管这个叫权责缺口：执行权交出去了，验收权没跟上。权力出得去，责任回不来。

重要的是验收，它该怎么写

验收这栏，如果写成"做完发我"。等于没写。

验收要写成它必须给你交出来的东西，我固定用三句：

第一句，总数能回算。 首页那个总数，我能从原始表里一步步加回来。

第二句，口径一致。 从头到尾用同一把尺子量。比如算销售额，这个月按下单那天算，下个月就不能改成按收到钱那天算；金额说了按含税，就别有几行填成不含税。尺子一换，两个月的数摆一块儿就没法比了。

第三句，每个结论有来源。 它说某个渠道下滑明显，后面得挂上是从哪张表哪一列看出来的。

直接拿去复制：

```
把 D:\销售\上半年 里所有Excel合成一张总表，按部门算环比，出一张柱状图。
原表别改别删，金额一律按含税口径，缺月份的行单独列出来别替我补。
结果存成 D:\销售\上半年汇总.xlsx，图放第二个工作表
。做完告诉我合了几个文件、总共多少行，总额跟原表加起来对不对得上。
```

> 小技巧：验收别在原来那个窗口问。 它交完活，你在同一个对话里问一句有没有问题，它大概率说没问题，因为它是顺着自己刚才的思路又看了一遍，等于自己给自己判卷。最好新开一个任务，扔给它三样东西：原始材料、它做出来那份成品、你那三句验收标准，让它当个刚来的人挑毛病。

## 第6章 你的规矩该写在哪儿

这次说清楚了要简体中文、小标题别套引号、字数控制住，下次开个新对话，又要从头再说一遍。烦死。

先别急着去找记忆功能。就拿"一律简体中文"这句话说：你在对话框里说，它这一次听；写进项目的指令栏，这个项目以后每个任务都听；写进记忆，换哪个项目它都听。

先按这条规矩管几个项目、管多久来选

它记的东西最后都落成文件：第一层云端记忆是服务器给你生成的画像，每次对话开头自动带上，不用你管；第二层用户级记忆在 ~/.workbuddy/MEMORY.md 这个文件里，想手动增删改，直接打开它改；第三层工作空间记忆在工作空间的 .workbuddy/memory/ 目录里，装的是每日日志和项目笔记。

牛马是管明白了。接下来该给他配家伙、配帮手了。

## 第7章 技能、专家团、连接器、助理，这四样怎么用

技能：把一件事的完整流程打包好。 装好一个技能，你一句话它就执行到底。零成本里最值得先装的四个：Agent Browser（让它自己开网页、点击、截图、读信息）、办公文档四件套（Word/Excel/PPT/PDF一把梭）、Local Whisper（本地语音转文字，不用API Key）、Web Search（联网搜索）。
 专家和专家团：区别很大。 专家是封装好的垂直角色，覆盖内容创作、数据分析、电商、抖音、销售、品牌、小红书、招聘。你不知道提示词怎么写的时候，先找对应的专家，方法和视角都完美定好。

专家这个非常好用，和普通的对话有啥区别呢？比方说这个小红书运营专家

```
D:\我的个人工作台
├─ 00-收件箱        暂时不知道放哪的先丢这儿
├─ 01-我的资料      你的身份、目标用户、风格、工作规则
├─ 02-进行中项目
├─ 03-内容生产
├─ 04-日常办公
├─ 05-交付成果
└─ 06-归档
```

我用小红书运营专家 写出的笔记，段落清晰 ，字数适中，还配有表情，违禁词也筛选 整体可以打到80分左右

```
读 D:\台账\本月.xlsx，出一份三页的周报，商务风，带图表，导出PDF。
台账原文件别动，数字直接引用别自己推算，没有台账数据支持的结论一句都别写。
存到 D:\交付\周报.pdf。
做完把每个结论对应台账的哪几行列给我。
```

但是我用普通对话以同样的提示词写一篇笔记，内容和风格就失去了小红书的风格 整体只能算及格

专家有专属的规则和更专业的设置方向，所以专家用起来真是爽到飞起啊

而且还有美团生活助手，可以领取满40减20的外卖券，而且还是可以设置每天自动领取， 感觉这里以后都能变成一个流量渠道入口

专家团呢是一个agent团队，一句话下去，几个角色分工干。它比单用技能强在两点：一是审阅，每件事在单独窗口做，做完由另一个不带历史上下文的agent来审，判断更中立；二是并行，两件事能同时跑，不用排队。你拉一整个团队来办事肯定 积分哗哗消耗，如果是小事就别用了。

连接器：不光是把腾讯自己的生态打通。 QQ邮箱、腾讯文档、腾讯乐享、腾讯会议、腾讯网盘、TAPD，还有飞书，网易邮箱、百度网盘、金山文档 应有尽有啊，这个就可太方便了，这个你必须用起来，用了你就知道有多爽了

配置也很简单，以QQ邮箱为例：连接器页面找到卡片点加号，用QQ邮箱App扫码授权，手机确认，卡片旁边出现绿点就通了。通了之后这些指令直接能发：

- 找出最近一个月含报价单附件的邮件
- 把跟XX项目相关的邮件线程汇总一下
- 找到那份季度规划文档，提炼核心要点
- 读取本周工作台账，生成周报，保存回腾讯文档（这条叫闭环回存，结果自动传回云端，不用你手动复制）
- 这个培训录音很重要，去腾讯会议里取文字转写，把重点提炼成纪要
比方说你用腾讯会议开完会，回到WorkBuddy说一句，它自动去会议里取转写、提炼纪要，老方便了。

我自己最受用的就是这个飞书连接器了。飞书里有着非常多我自己的各种文章纪要，我就让它用MCP把飞书和本地写的的地方一并连上。写完一句话，它把文章传到飞书，还顺手排好版，排出来相当好看。每一个能节省的麻烦，都是愿意付费的支点啊。

这个思路能推广到任何你常用的协作平台。哪个是你放东西的主阵地，就把哪个连进来，把你之前的生态全部纳进来。老嗨了。

助理：把它接到你本来就在用的地方。 左侧还有个入口叫助理，很多人以为是再造一个聊天机器人，其实它是把WorkBuddy的能力接到你平时用的平台里。当前版本能接的有微信小程序、微信助理、微信客服号、企微助理、QQ机器人、飞书等等。接好之后你在手机上就能直接给它派活，人在外面，活在家里的电脑上跑。这个本质就是个远程，要多方便有多方便。

用过以上，我只能说：绝！

装备家伙都凑齐了。但说到底还是要你去push一步它走一步。有没有办法让它自己按点上班？

## 第8章 定时任务怎么设，什么时候才该交给它自动跑

重复、规则明确、不用你实时盯的活，设成定时任务，它自己跑。进自动化页面点添加，填名称、工作空间、提示词、选模型和技能、设定时规则就行，还能开推送到微信小程序。常用的几个：

- 每天9点读取前一日数据，生成日报，企业微信发给指定同事
- 每周五18点，把D盘核心数据备份到移动硬盘，生成备份记录
- 每周一10点抓竞品官网的产品动态和价格，整理成表发我邮箱
- 工作日每天8:30，拉天气、日程、待办，生成晨间播报推到微信
做外贸的最爱建这类流程。每天的销售晨报、每周的竞品价格变动，全交给定时任务，人只管看结果。

但别第一天就设定时。 同一套流程，手动成功跑过两三次，再交给定时任务。

手动跑顺了再撒手，这牛马就算带出来了。

这些你现在都懂了。来直接动手走一遍。

## 第9章 现在动手：六字段自测和七天练法

打开一个空白对话框。拿手边最烦的重复活，试着填一遍六字段。

输入、目标、边界、过程、输出、验收。

哪个不知道咋写就是你还没想清楚。材料在哪、成品什么样、什么算做好了，这三个问题你得想好答上来。

没装过WorkBuddy的，今天跑通这三步：官网下载装好，从上面那10条指令里挑一条你每周都要重复的活，按六个字段写清楚，跑一遍。

跑通了想练熟，下面这七天走起。

第一到第三天，跑通三件小事。 别挑难的。整理十张截图、把一篇文章总结成三百字、把一份会议记录变成一张待办清单。每件事都按六个字段写，写完发，收到结果就完事。这三天别指望产出什么，主打一个练习。

第四到第七天，只练把活说清楚。 每天挑一件，只练目标、边界、输出、验收这四个。产物漂不漂亮无所谓，主要是看你能不能说清楚。

就跟你带过实习生、交代过同事、验收过外包一样。只是换成了软件。

你身边要是有人装完就放着，或者试了一次就骂它不行，就把这篇转给他。
